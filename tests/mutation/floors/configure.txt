# tools/configure.py (package P8). mutmut 3 writes a whole copy of a function
# for every mutant of it, and Python's parser is superlinear on a file of
# f-strings: with validate() at 614 lines the mutated file was 1.1M lines and
# its generation never finished. Split a table a function (main, gen_cmake and
# generate_icons too), it is 218k lines, 18 s to generate and 106 s to parse.
#
# The tests are what reaches configure.py in-process: the properties, and the
# classes of configure_test.py that call it rather than start it as a program
# (which would compile the 11 MB mutated file on every start) or read its text
# as a gate (ConfigureRejectionCoverageTest parses validate(), a trampoline in
# mutmut's copy). The selected mutants are the functions those reach; left
# out, each with its reason: main(), argument_parser(), answer(), generate(),
# report(), compute_stamp() and _print_matrix() run only as a program;
# write() is the one function every test replaces; schema() is ConfigTablesTest's,
# which starts the program too; the icons need Pillow and draw pixels nobody
# compares; warn() and the two __init__ are a line each.
# ToolsReadBackTest starts a compiler, CMake or a JVM for each example: it is
# what vouches for the readers BuildFilesTest uses, which kill the same mutants.
