# Every public function of include/rmp/ that no property holds yet to the
# campaign's resilience rules -- no UB on any input, a documented safe value and
# one RMP_REPORT_ONCE for a game's mistake, no NaN kept in state, no state
# changed by a refusal. tests/campaign_test.py reads the headers' AST
# (tools/coverage_report.py's walker), and fails a public function that is
# neither here nor named by `// covers: <function>` in a tests/property/*_prop.cpp
# -- a file whose code calls it: a covers line alone holds nothing.
#
# This list ONLY SHRINKS: a function a property covers fails until its line goes,
# a line naming a function that is gone fails, and a new public function arrives
# with its property -- or, written here by hand, with a reviewer reading why.
# The keys are tools/coverage_report.py's, as tools/untested_api.txt spells them.
#
# Measured 2026-10-11 against main 0b80c3f: 296 functions. Each block says which
# package of Stage E takes it. Stage D's eight -- rmp::app::stretch() and
# set_stretch(), and rmp::ui's at, overlay, tooltip and notify -- were written in
# by hand at its merge, into the blocks of the packages that take their headers
# after Stage D: none of them had a property yet, as no function of theirs did.
