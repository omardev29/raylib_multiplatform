# resources/ of the assets example

Every file here is loaded by name from `src/main.cpp`. An example directory
with its own `resources/` reads that one instead of the game's -- that is what
`rmp_add_game()` in the root CMakeLists.txt sets `RESOURCES_PATH` to.

| File | What | Licence |
|---|---|---|
| `rabbit.png` | Kenney's Animal Pack, the same picture the game uses | CC0, `License-rabbit.txt` |
| `ui.ttf` | DejaVu Sans, subset to Latin-1 with fontTools so it weighs a few KB | Bitstream Vera + public domain, `License-ui.ttf.txt` |
| `jump.wav` | 0.15 s of a decaying 660 Hz sine, generated by a ten-line script | none needed |
| `level1.json` | three keys, to have bytes to load | none needed |
